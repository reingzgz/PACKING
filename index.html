Reglas de lectura del código

Sincronización online

Guarda una copia de los datos de este dispositivo en el propio repositorio de GitHub donde está publicada la app, en un archivo sync/packing.json, para poder traerla a otra PDA. No hace falta ningún servidor. Cada PDA decide cuándo subir y cuándo traer: no es automático ni en tiempo real.

El token es la contraseña que permite a la app escribir en tu repositorio. Se guarda sólo en este dispositivo y nunca viaja dentro de los datos que se suben.

De dónde saco el token — paso a paso
  1. Entra en github.com con tu cuenta, en un ordenador.
  2. Arriba a la derecha, pulsa tu foto → Settings.
  3. Baja del todo en el menú de la izquierda → Developer settings.
  4. Personal access tokens → Fine-grained tokens → botón Generate new token.
  5. Nombre: packing. Caducidad (Expiration): la más larga que te deje, o No expiration.
  6. En Repository access marca Only select repositories y elige el repositorio donde está publicada esta app.
  7. En Permissions → Repository permissions, busca Contents y ponlo en Read and write.
  8. Abajo, Generate token. Sale un código largo que empieza por github_pat_: cópialo ahora, porque GitHub no vuelve a enseñarlo.
  9. Pégalo aquí arriba y pulsa «Guardar estos datos de conexión». Repítelo en cada PDA.
